## Publish with GitHub Pages

1. Push the repository contents to the `main` branch of a public GitHub repository.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/(root)` folder, then save.
5. Once GitHub Pages finishes deploying, open the site URL shown in the Pages settings.

The site is a static page and needs no build step. When adding a chapter, place its image in the repository root and add a matching card in `index.html` and row in this README.
